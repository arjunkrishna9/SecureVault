# SecureVault

SecureVault is an offline password manager Android application designed to securely store and manage your passwords and account credentials locally on your device.

## About the Project

SecureVault was developed as an Android application focused on providing a simple and private way to manage login credentials.

The application allows users to create an account and store credentials such as usernames, email addresses, passwords, and application/website names in a personal vault.

The application works completely offline, so the stored data does not need to be sent to an external server.

## Features

- Create and manage a user account
- Secure login system
- Store application and website credentials
- Store usernames and passwords
- Show/hide passwords
- Copy username and password easily
- Add, update, and delete saved credentials
- Confirmation dialogs for important actions
- Long-press to reorder password entries
- Display the last updated time
- Password vault with a clean and simple interface
- Offline data storage
- Multiple user accounts
- Password recovery using security information and recovery PIN
- Screenshot prevention for better privacy

## How It Works

1. Create a SecureVault account.
2. Log in to your account.
3. Add your application or website credentials.
4. Store the username and password in your vault.
5. View, update, copy, reorder, or delete your saved credentials whenever required.

 ## Important Note

- **Always press the Logout button after completing your work.**
- If you do not log out, your current session will remain logged in until you manually press **Logout**.
- For better security, make sure to log out when you are finished using the application.

## Project Status

SecureVault is a learning/personal project and may receive additional features, security improvements, and UI enhancements in the future.

## Privacy & Security

SecureVault is designed as an **offline password manager**.

- No internet connection is required for normal operation.
- Password data is stored locally on the device.
- No credentials are uploaded to a remote server.
- No personal information is transmitted to external services.
- The application is designed to keep your vault data on your device.

> **Important:** SecureVault is a personal/learning project and should not be considered a replacement for professionally audited password managers.

## Database

SecureVault uses **Room Database** for local data storage.

The application stores vault-related information locally on the device, allowing the application to work without an internet connection.
